# Security policy

## Supported code

iMusic is under active development and does not yet publish signed releases.
Security fixes are applied to the latest default branch. Older commits and forks
are not maintained separately.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting](https://github.com/LinZong/iMusic/security/advisories/new)
to contact the maintainers. Do not open a public issue containing an unpatched
exploit, credentials, pairing codes, or private library data.

Include the affected commit and platform, reproduction steps, expected impact,
and a minimal example with synthetic data. Relevant areas include Wi-Fi upload
authorization, file and archive handling, backup restore, local data access, and
optional cloud synchronization. Please allow time to investigate before publishing
details. This project does not promise a response deadline or offer a bug bounty.

For ordinary playback, layout, or build problems, use a bug report instead.
