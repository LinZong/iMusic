# Application icon assets

`Scripts/generate_assets.swift` owns the purple music artwork and generates the
committed PNGs in `Apps/Resources/Assets.xcassets/AppIcon.appiconset`.

The macOS asset-catalog images target the native macOS 14/15 icon presentation:

- An RGBA canvas with transparent outer margins and rounded corners.
- A continuous rounded rectangle drawn using SwiftUI's native path geometry.
- A centered 824-point face on the 1024-point design canvas, with a 185-point
  continuous corner radius. These are the project's artwork dimensions, calibrated
  against the system icon proportions on macOS 15.
- A restrained shadow whose offset and blur scale with the output resolution.
- Separate 1x and 2x images for 16, 32, 128, 256, and 512-point icon slots.

The iOS and iPadOS catalog uses universal 1024-pixel images for three appearances:

- `ios-1024.png`: the opaque, full-bleed sRGB default artwork and App Store master.
- `ios-1024-dark.png`: the same music silhouette in a subdued lavender, on a
  transparent sRGB background so the system can provide its dark background.
- `ios-1024-tinted.png`: a grayscale silhouette on black, encoded in Gray Gamma 2.2
  without alpha, ready for the user's system-selected Home Screen tint.

All iPhone and iPad sizes, including Home Screen, Settings, and Spotlight variants,
are generated by the asset compiler from these masters. Do not add Mac-style
margins, corner masks, or drop shadows to the iOS artwork: the system supplies
those effects. The default image remains available on iOS/iPadOS 17; the system
selects supported appearance variants on newer versions. The symbol geometry stays
identical across appearances and platforms.

These are bitmap asset-catalog icons, not layered Icon Composer artwork. On newer
systems, clear appearances and Liquid Glass treatments are supplied by the system.
The default artwork is intentionally unchanged; this update adds explicit control
over dark and tinted appearances.

Regenerate the assets from the repository root:

```sh
xcrun swift Scripts/generate_assets.swift
```

Build with `./Scripts/build_macos_release.py` to compile the Mac icon catalog into
the application. Relaunch the rebuilt application to inspect its Dock appearance.
Check both small and Retina representations, transparency, and the compiled icon.

The PNG asset-catalog path supports macOS 15 directly. Apple's newer layered icon
workflow has different masking behavior; keep that distinction when updating the
artwork. References: [asset catalog configuration](https://developer.apple.com/documentation/xcode/configuring-your-app-icon)
and [Apple's introduction to the newer icon system](https://developer.apple.com/videos/play/wwdc2025/220/).

For iOS/iPadOS, build the `iMusic` scheme for an iOS Simulator destination, then
install the result on both an iPhone and an iPad simulator. Inspect the Home Screen
at small and large icon sizes, and select Light, Dark, and Tinted from Home Screen
customization. Verify the generated bundle declares both `CFBundleIcons` and
`CFBundleIcons~ipad`. Changing the app's own appearance setting does not select the
Home Screen icon appearance.

References: [Apple's app icon guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons)
and [dark and tinted asset variants](https://developer.apple.com/documentation/xcode/configuring-your-app-icon).
